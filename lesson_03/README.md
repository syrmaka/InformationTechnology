## Задание 3 · Тег на сайте, источник и отчёты GA4

### Если события не появляются

| Признак | Что проверить |
| --- | --- |
| Тег не обнаружен | Тег стоит перед `</head>`, сайт опубликован, публикация в статусе READY |
| События двоятся | Тег вставлен дважды на одну страницу |
| Realtime пуст | Сайт открыт по публичному адресу (не файл с диска) |
| Источник (not set) | Переход сделан по ссылке с параметрами `utm_source`, `utm_medium`, `utm_campaign` |
| В «Отчётах» пусто | Данные в отчётах появляются в течение суток (в Realtime — сразу) |
